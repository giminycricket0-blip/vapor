These are public, synthetic TLS fixtures for NativeContentIOTest only. They are
packaged in the test APK, never the production APK or Android trust store.

localhost.p12 contains a disposable RSA key and the self-signed localhost.pem
certificate (DNS SAN: localhost). Its non-secret password is `vapor-test-only`.
unrelated.pem is a different self-signed certificate used to prove trust rejection.
The certificates expire in October 2036. No real service uses these keys.

The test serves generated bytes over a loopback TLS socket. It checks successful
HEAD/download, certificate and hostname rejection, truncated bodies, and HTTP
errors through the production curl/OpenSSL JNI path without external networking.
